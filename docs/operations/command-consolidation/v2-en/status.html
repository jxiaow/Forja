forja status

Responsibility: Lightweight read-only status view. No deep SSH probing, no full toolchain detection, no config modification.

Syntax

forja status [--process] [--workspace <path>] [--json] [--lang <locale>]

Behavior

  1. Parse workspace.
  2. Read active target metadata.
  3. Read Qt/SDK/Sync/Remote settings summary.
  4. When no active target: scan candidate counts, do not guess, return forja list + forja use.
  5. When active target exists: verify project exists, mode/arch valid, runAt configuration complete.
  6. --process returns runtime field; without it, only readiness summary.

Absorbed Commands

forja qt status, forja sdk status, forja remote status, forja sync status, forja qt ps, forja remote qt ps

Note: The following old commands have been moved to forja list remote (pure config enumeration): forja remote workspace status, forja remote forja-bin status, forja remote build-order status, forja remote transfer status

Boundary with list

  • status answers "can it be used", only outputs minimal summary needed for readiness judgment (server/remotePath/locked/workspaceMode).
  • list remote answers "what is configured", outputs all remote configuration details (workspace/bin/build-order/transfer/repos).

Result

interface StatusResult extends ForjaJsonResult {
    action: 'status';
    readiness: Readiness;
    toolchain?: ToolchainSummary;
    remote?: RemoteStatusSummary;
    sync?: SyncStatusSummary;
    runtime?: RuntimeState;    // only with --process
}

interface ToolchainSummary {
    qt?: { path: string; version?: string };
    vs?: { path: string; version?: string };
    jom?: string;              // Windows only
    make?: boolean;            // POSIX only
}

interface RemoteStatusSummary {
    runAt: 'local' | 'remote';
    server?: { id: string; name: string; host: string };
    remotePath?: string;
    remoteForjaBin?: string;
    locked?: boolean;
    workspaceMode?: 'legacy' | 'staged';
}

interface SyncStatusSummary {
    enabled: boolean;
    server?: { id: string; name: string; host: string };
    remotePath?: string;
}

ok Determination Rules

  • Any readiness dimension is blocked, missing, or unknown → ok: false
  • All dimensions are ready, configured, or not-selected → ok: true
  • runtime does not affect ok value
