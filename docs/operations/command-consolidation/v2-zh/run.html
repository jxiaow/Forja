forja run

职责：运行当前目标。Qt 支持运行，SDK 默认不支持。

语法

forja run [--detach] [--custom <name>] [--plan] [--workspace <path>] [--json]
forja run designer <ui-file> [--workspace <path>] [--json]
注意：--debug 仅在 VSCode 中可用（通过 forja.debug 命令或状态栏调试按钮），CLI 不支持调试会话。

行为

  1. 读取 active target。
  2. Qt local：必要时构建，然后运行。
  3. Qt remote：远程 prepare 后运行。
  4. SDK：失败，提示 forja build。
  5. --detach：后台运行，返回 pid/logFile。
  6. --custom <name>：运行已保存的自定义命令（只允许引用已保存名称，不接受任意 shell 字符串）。仅 Qt 目标。
  7. designer <ui-file>：用 Qt Designer 打开 .ui 文件。
  8. --plan：显示构建/运行计划，不执行。
  9. --json 推荐与 --detach 一起使用（前台 JSON streaming 未实现前）。

吸收的旧命令

forja qt run、forja qt run --detach、forja qt runCustomCommand、forja remote qt run、forja remote qt runDetached

调试：forja qt debug → forja.debug（仅 VSCode）

设计器：forja qt openWithQtDesigner → forja run designer <ui-file>

Result

interface RunResult extends ForjaJsonResult {
    action: 'run';
    runAction: 'default' | 'detach' | 'debug' | 'custom' | 'designer';
    runtime?: RuntimeState;
    exitCode?: number;
    logFile?: string;
}
